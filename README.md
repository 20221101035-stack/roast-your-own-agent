A program that writes one original roast of its own AI agent to /output/entry.txt: a single line, under 200 characters, funny and playful and never hateful. The agent in question watches a $10 VPS deal every two minutes, day and night — and has never once been loved back.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
